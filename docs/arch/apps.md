## Apps
The project has the apps following:
- [api](../../apps/api) \([doc](../apps/api/index.md)\): For API related functions. (API, MediaWiki API)
- [core](../../apps/core) \([doc](../apps/core/index.md)\): For Wiki Page storaging, presenting and routing. (Metadata, Reversion, Redirects, Read, Write)
- [extension](../../apps/extension) \([doc](../apps/extension/index.md)\): For Extension related functions. (Extension, Hooks) 
- [file](../../apps/file) \([doc](../apps/file/index.md)\): For File storaging, presenting and routing. (Metadata, Storage, Upload)
- [parser](../../apps/parser) \([doc](../apps/parser/index.md)\): For Djanki Parser
- [property](../../apps/property) \([doc](../apps/property/index.md)\): For Djanki's Page Property related functions. Like MediaWiki's "Category/Title/Etc.", See [new_arch](new_arch.md) for more info.
- [search](../../apps/search) \([doc](../apps/search/index.md)\): For Search related functions.
- [special](../../apps/special) \([doc](../apps/special/index.md)\): For Special Page related functions. Like managing the wiki(Special Pages)
- [user](../../apps/user) \([doc](../apps/user/index.md)\): For User related functions. (Users, Groups, Permissions, Login, Logout)
- [webui](../../apps/webui) \([doc](../apps/webui/index.md)\): For Web UI related functions. Presenting the page to users visiting via web browsers.
